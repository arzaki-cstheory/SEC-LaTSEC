# SEC-LaTSEC
SageMath scripts for SEC and LaTSEC. The scripts are in Jupyter notebook files, and the scripts run well on SageMath 10.7.
1. Experiment-Getting-G is the G search, 
2. G-Related-Bounds gives α, ‖Ĝ‖ and ‖G‖, 
3. Canonical-Reconstruction-Vector gives β̂, ω̂ and the figures, 
4. Parameter-Setting is the parameter search.
